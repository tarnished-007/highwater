# Highwater

Chrome extension for Instagram (Explore page **and** profiles) that sorts posts
by **views, likes, comments, or upload date** and filters them by **topic
keywords** — data Instagram already sends to your browser but never shows in
the grid.

## How it works

- `interceptor.js` runs in the page's main world and hooks `fetch`/XHR. It reads
  the JSON responses Instagram delivers to the Explore page (no extra requests
  are made to Instagram's servers) and extracts each reel's view count, likes,
  caption, thumbnail, and author. Extraction is shape-based (it recognizes what
  a reel object looks like), so it tolerates Instagram renaming endpoints.
- `content.js` collects the reels (deduped), filters them against your keywords
  (matched against caption + hashtags + username), sorts by views, and renders
  the side panel.

## Build the store package

```sh
node build.js
```

Writes `dist/highwater-<version>.zip` — `manifest.json` at the ZIP root, only the
files the extension actually needs. Bump `version` in `manifest.json` first; the
Chrome Web Store rejects a re-upload of an existing version.

## Use

- Works on the Explore page and on any profile — scroll and posts are collected.
- Click the round **▶ button** (bottom-right) to open the panel. The badge shows
  how many posts have been collected — keep scrolling to collect more.
- Pick a sort: **Most views / Most likes / Most comments / Newest / Oldest**.
  Each row shows views, likes, comments, author, and upload date.
- Type a keyword (e.g. `content`, `#contentmarketing`, `hook`) and press Enter
  to add a topic chip. Chips do two jobs: they **filter** the collected list,
  and **clicking a chip searches Instagram for that topic** (via Instagram's
  own search API — the same engine as the mobile app's topic search) and pulls
  the resulting reels straight into the panel, no page navigation. Use a
  `#hashtag` chip for hashtag results, a plain phrase (e.g. `content writer`)
  for relevance search. The × removes a chip. No chips = show everything.
- **Auto-scroll** scrolls the page for you so posts keep loading into the
  collector hands-free. The collection persists across page navigation, so
  browsing several topic feeds builds one combined, sorted list.
- Click any row to open the post in a new tab. **Clear collected** resets the
  session (do this when switching profiles so counts don't mix).
- **Export ⤓** downloads the shown list (topic chips applied) as a real Excel
  workbook (`.xlsx`) — Link, Views, Likes, Comments, Username, Date — sorted
  by views, formatted as a red Excel Table with banded rows, a frozen header,
  clickable links, and sort/filter dropdowns on every column. Opens in Excel
  and Google Sheets. (Generated by `xlsx.js`, a small hand-rolled writer.)

## Limits

- Only sorts what has loaded — scroll to collect more; there is no "all of
  Explore".
- Desktop Chrome (and Chromium browsers) only; Instagram's mobile app can't be
  extended.
- Keyword filtering depends on captions; reels with empty captions can't be
  keyword-matched at all.
- Instagram changes its internals periodically; if the panel stops collecting,
  the extraction shapes in `interceptor.js` are the place to update.
